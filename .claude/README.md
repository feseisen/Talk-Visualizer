# `.claude/settings.json` の雛形について

Claude Code を分析役にするときの許可の設定です（手順は `prompts/for-claude-code.md`）。
**置き場に合わせて書き換えてください**。雛形は「素材は `live/` に置き、コマンドはこのツールのルートフォルダ（kiku.html のあるフォルダ）から打つ」前提で書いてあります。

## 何を止め、何を通すか

| 区分 | 行 | 意味 |
|---|---|---|
| deny | `Read(./live/*.txt)` `Read(./live/**/*.txt)` と、同じ形の `*.tsv`・`*.vtt` | メモ帳・文字起こし（素材。素材の名前は `.txt`・`.tsv`・`.vtt` のどれか）をファイル読み取りのツールで開かない |
| deny | `Read(./live/*.src.jsonl)` `Read(**/*.src.jsonl)` | 素材ログを開かない（どのフォルダにあっても） |
| deny | `Write(**/*.src.jsonl)` `Edit(**/*.src.jsonl)` | 素材ログをツールで書き換えない（素材ログに書くのはページと `rt.py` だけ） |
| deny | `Write(**/*.next.json)` `Edit(**/*.next.json)` | 覚え書きを手で書かない・書き換えない（覚え書きは `rt.py next` が作り、`append` がそれと突き合わせる。手で触ると突き合わせの意味が無くなる） |
| deny | `Write(**/*.owner)` `Edit(**/*.owner)` | ロックファイル（`.owner`）をツールで書き換えない（`rt.py open` が素材の隣に置き、1 つの素材に開けるログを 1 つにするファイル。書くのは `rt.py` だけ）。ただし `rm` などのコマンドで消すことは、この設定では止めていない。消えていれば、書き終えたあとの監査（`tools/audit_r2b.py`）が「隣にロックファイル … がありません」と書く（違反には数えない）。ロックファイルを別のログに向け直していれば違反に数える |
| deny | `Write(**/*.watch.json)` `Edit(**/*.watch.json)` | `watch` の状態ファイル（`.watch.json`）をツールで書き換えない（実行中の `watch` を示すファイルで、中身は判断ログの名前と時刻と番号だけ。書くのは `rt.py` だけ。このファイルに書かれた名前と違うログを指定したコマンドは断られる） |
| deny | `Bash(cat:*)` … `Bash(py -3 -c:*)` | よく使う読み取りのコマンドを止める（`cat`・`head`・`tail`・`grep`・`rg`・`sed`・`awk`・`less`・`more`・`type`・`Get-Content`・`python -c` の類） |
| allow | `Bash(python tools/rt.py:*)`（`python3`・`py -3` も） | 判断ログのツールだけは毎回の許可なしに通す |
| allow | `Bash(python tools/audit_r2b.py:*)`（同上） | 終わってからの監査 |
| allow | `Edit(./live/*.batch.jsonl)` | 返事のバッチを書く |

判断ログ `live/<会議名>.jsonl` と覚え書き `live/<会議名>.next.json` を**開く**ことは止めていません（分析役自身の出力と、`next` が出した窓のコピーなので、開いても先は見えません）。覚え書きを**書く・書き換える**ことは上の deny で止めています。`rt.py` はコマンドの中で書くので、この deny の対象になりません。
バッチの書き先を deny の `Read` に入れないでください。Claude Code は既にあるファイルを書き換える前に読むので、読めないと 2 回目以降の書き込みが失敗します。

## 書き換えるとき

- 素材を `live/` 以外に置くなら、`Read(./live/…)` のパスをその置き場に直す。`./` はコマンドを打つフォルダからの相対、`/` で始めると設定ファイルの置き場からの相対、`//` で始めると絶対パス、`~/` はホームからの相対（Claude Code の説明のとおり。確かめた環境は無い）
- `python` でなく `py -3` しか無い環境では、`allow` の `py -3 …` の行だけが効く。コマンドの先頭もそれに揃える（`prompts/for-claude-code.md` 第6節）
- 読み取りのコマンドを足して止めたいときは `Bash(<先頭の文字列>:*)` の形で足す

## 確信の無いところ（実機で確かめていない）

- `Read(…)` の規則が `Grep`・`Glob` にも効くかどうか。Claude Code の説明では「ファイルを読む組み込みのツールすべてに効く」とあるが、この雛形で確かめてはいない
- `Edit(…)` の規則が `Write` のツールにも効くかどうか。説明では「ファイルを書き換える組み込みのツールすべてに効く」とある
- `Bash(cat:*)` の `:*` は「その文字列で始まるコマンド」を表す記号。古いバージョンでは別の書き方だった可能性がある
- `Bash(…)` の規則はコマンドの**先頭の文字列**でしか照合されない。`echo x; cat live/会議.txt` のように後ろに置かれた読み取りや、ここに無いコマンド（`od`・`xxd`・`strings`・`perl -ne` など）は止まらない。**だから「素材を直接開かない」は、設定ではなく分析役の側が守る**（`prompts/for-claude-code.md` 第3節）
- Claude Code が設定ファイルの知らないキーをどう扱うかが分からないので、この雛形には `permissions` 以外を書いていない。説明はこのファイルに置いてある
