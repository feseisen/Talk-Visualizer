# `.claude/settings.json` の雛形について

Claude Code を分析役にするときの許可の設定です（手順は `prompts/for-claude-code.md`）。
**置き場に合わせて書き換えてください。**雛形は「素材は `live/` に置き、命令文は 道具の根（kiku.html のあるフォルダ）から打つ」前提で書いてあります。

## 何を止め、何を通すか

| 区分 | 行 | 意味 |
|---|---|---|
| deny | `Read(./live/*.txt)` `Read(./live/**/*.txt)` と、同じ形の `*.tsv`・`*.vtt` | メモ帳・文字起こし（素材。素材の名前は `.txt`・`.tsv`・`.vtt` のどれか）をファイル読み取りの道具で開かない |
| deny | `Read(./live/*.src.jsonl)` `Read(**/*.src.jsonl)` | 素材ログを開かない（どのフォルダにあっても） |
| deny | `Write(**/*.src.jsonl)` `Edit(**/*.src.jsonl)` | 素材ログを道具で書き換えない（素材ログに書くのはページと `rt.py` だけ） |
| deny | `Write(**/*.next.json)` `Edit(**/*.next.json)` | 覚え書きを手で書かない・書き換えない（覚え書きは `rt.py next` が作り、`append` がそれと突き合わせる。手で触ると突き合わせの意味が無くなる） |
| deny | `Write(**/*.owner)` `Edit(**/*.owner)` | 持ち主の印を道具で書き換えない（`rt.py open` が素材の隣に置き、1 つの素材に開けるログを 1 つにする印。書くのは `rt.py` だけ）。ただし `rm` などの命令文で消すことは、この設定では止めていない。消えていれば、書き終えたあとの監査（`tools/audit_r2b.py`）が「印が無い」と書く（違反には数えない）。印を別のログに向け直していれば違反に数える |
| deny | `Write(**/*.watch.json)` `Edit(**/*.watch.json)` | `watch` の印を道具で書き換えない（回っている `watch` の目印で、中身は判断ログの名前と時刻と番号だけ。書くのは `rt.py` だけ。印の名前が違うログの命令は断られる） |
| deny | `Bash(cat:*)` … `Bash(py -3 -c:*)` | よく使う読み取りの命令文を止める（`cat`・`head`・`tail`・`grep`・`rg`・`sed`・`awk`・`less`・`more`・`type`・`Get-Content`・`python -c` の類） |
| allow | `Bash(python tools/rt.py:*)`（`python3`・`py -3` も） | 判断ログの道具だけは毎回の許可なしに通す |
| allow | `Bash(python tools/audit_r2b.py:*)`（同上） | 終わってからの監査 |
| allow | `Edit(./live/*.batch.jsonl)` | 返事のバッチを書く |

判断ログ `live/<会議名>.jsonl` と覚え書き `live/<会議名>.next.json` を**開く**ことは止めていません（分析役自身の出力と、`next` が出した窓の写しなので、開いても先は見えません）。覚え書きを**書く・書き換える**ことは上の deny で止めています。`rt.py` は命令文の中で書くので、この deny には当たりません。
バッチの書き先を deny の `Read` に入れないでください。Claude Code は既にあるファイルを書き換える前に読むので、読めないと 2 回目以降の書き込みが失敗します。

## 書き換えるとき

- 素材を `live/` 以外に置くなら、`Read(./live/…)` のパスをその置き場に直す。`./` は命令文を打つフォルダからの相対、`/` で始めると設定ファイルの置き場からの相対、`//` で始めると絶対パス、`~/` はホームからの相対（Claude Code の説明のとおり。確かめた環境は無い）
- `python` でなく `py -3` しか無い環境では、`allow` の `py -3 …` の行だけが当たる。命令文の先頭もそれに揃える（`prompts/for-claude-code.md` 第6節）
- 読み取りの命令文を足して止めたいときは `Bash(<先頭の文字列>:*)` の形で足す

## 確信の無いところ（実機で確かめていない）

- `Read(…)` の規則が `Grep`・`Glob` にも効くかどうか。Claude Code の説明では「ファイルを読む組み込みの道具すべてに効く」とあるが、この雛形で確かめてはいない
- `Edit(…)` の規則が `Write` の道具にも効くかどうか。説明では「ファイルを書き換える組み込みの道具すべてに効く」とある
- `Bash(cat:*)` の `:*` は「その文字列で始まる命令文」の印。古い版では別の書き方だった可能性がある
- `Bash(…)` の規則は命令文の**先頭の文字列**にしか当たらない。`echo x; cat live/会議.txt` のように後ろに置かれた読み取りや、ここに無い命令（`od`・`xxd`・`strings`・`perl -ne` など）は止まらない。**だから「素材を直接開かない」は、設定ではなく分析役の側が守る**（`prompts/for-claude-code.md` 第3節）
- Claude Code が設定ファイルの知らない鍵をどう扱うかが分からないので、この雛形には `permissions` 以外を書いていない。説明はこのファイルに置いてある
