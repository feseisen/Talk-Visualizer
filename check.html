環境を調べる

このページは、この PC のブラウザで何が動くかを調べて一覧にします。鍵は持ちません。会議の内容も送りません。
外へ要求を出すのは API の項目だけです。行き先は 2 つの API の住所だけで、ほかの住所にはブラウザがつながないよう、ページに決まりを入れてあります。
API 1 つにつき、多くて 3 本です。中身の無い呼び出し（送る要求）を 1 回送り、その前にブラウザが下見の要求を自分で 1 回出します。送る要求の返事が読めず、案内（転送）が返ったとも分からなかったときだけ、届いたかを見る要求（見るだけの要求）を 1 回出します。2 つの API で合わせて多くて 6 本です。どれにも鍵とクッキーは付けず、会議の内容も入れません。
案内（転送）が返っても、どの要求もその先へは行きません（同じ住所の中の案内も追いません）。時間切れにした要求は、その場で取り消します。
結果の「可」は、その場で確かめられたものだけです。確かめられなかったものは「不可」にして、補足に分かったことを書きます。API の項目は、鍵の無い呼び出しを断る返事（状態 401）が、その API の断り方の形で返ったときだけ「可」です。401 でも形が違えば、社内の中継が止めた可能性があるので「不可」にします。
クリップボードを調べるとき、貼り付け板に短い文を 1 つ書きます（いま写しているものは消えます）。残しておきたいものがあれば、先に貼り付けてから「調べる」を押してください。

サーバから開くと、このページの住所（どこから開いたか）が API 側に伝わります。ファイルとして開いてください（展開したフォルダの check.html をダブルクリックする）。
