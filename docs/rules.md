# この道具の規則（R1〜R11）

この道具に手を入れる人（画面を直す人、分析役への指示を直す人、記録の形を変える人）のための決まりです。
`R1`・`R2b` などの番号は、コードの注記や試験の名前にそのまま出てきます。

ねらいは一つです。**話を聞いている人が、頭の中で話の組み立てを作る手間を減らすこと。**
画面を見た人に、構造を自分で読み解かせるようでは役に立っていません。下の規則は、どれもこのねらいから来ています。

---

## 必ず守るもの

### R1. 上から下へ、話された順に置く。置いた位置は動かさない

21 分目に出た話は、あとで会議全体を包む問いだったと分かっても、21 分目の所に置いたままにします。上へ引き上げません。

- 格が上だと分かったときは、左へ寄せる（インデントを浅くする）ことだけで示します
- 前のいくつかのカードが一つのまとまりだったと後から分かったときは、分かった時刻の所に括りの印を置き、範囲に入るカードを右へ寄せて見せます
- なぜか: 並べ替えると、いま話がどこにあるのか、少し前に何を話していたのかを、縦の位置から読み取れなくなります。そうなると、この道具を使う意味がありません

### R2. 先を読まない

- 素材は頭から、窓一つ分ずつ読みます。いまの窓の判断を記録に書き終えるまで、次の窓は開けません
- 一度書いた記録は直しません。直すときは訂正を書き足します（`fix`・`rename`）
- 素材に混ざっている章見出しや、配られた議題を、話の構造として使いません。話し手が口に出して数を宣言したもの（「三点あります」など）だけを `list` に書きます

### R2b. 中心は「聞きながら処理すること」。画面と記録は、そこから出てくるもの

次の順番を守り、入れ替えません。

1. 聞きながら処理する。先の素材を見ずに、一つずつ拾い、判断し、まとめていく
2. その処理の跡をそのまま残す。直したこと、保留にしたこと、仮に付けた名前、候補が入れ替わったことも、起きた順のまま
3. 残した跡を、あとから時間を追って見返せる形にする

禁じ手は、全部を読み終えて結末を知ってから整ったカードを作り、それを時刻に合わせて出したり隠したりすることです。出し方をいくら工夫しても、中身があとから書いた要約なら、この道具の記録にはなりません。

**確かめ方: 画面に出ている一つひとつについて、その時刻にはもう分かっていたことか、を問う。**分かっていなかったものが一つでも出ていれば違反です。見せ方ではなく、作った順番の問題です。見出しや説明の文にも同じ問いを当てます。

### R2c. 先の見込みは `note` へ。カードには、語られたことだけ

見込み・感想・迷いは、その窓の `note` に書きます。カードにするのは、それが実際に語られた窓に来てからです。

見込みが当たったときほど気を付けます。当たった見込みをカードにすると、まだ分かっていなかったことが、その時刻に分かっていたかのように残り、事実と食い違います。見込みをカードにしなければ、外れた見込みをあとで取り消す訂正も要りません。

### R3. 版を残す

作り直す前に、元に戻せる形で残します（このリポジトリでは Git の履歴がその役です）。前の版へさかのぼる、元に戻す、二つの版を並べて比べる、の三つができること。

## 設計の規則

| | 規則 |
|---|---|
| **R4** | **階層の分け方は、話ごとに決める。**決まった型（序論・本論・結論など）に当てはめない。段が 3 つで足りる話もあれば、10 要る話もある |
| **R5** | **記号が表すのは段の深さではなく、ものの種類。**◆ は区切り、● は項目。深さは左右の寄りで表すので、段が増えても記号の種類は増やさない |
| **R6** | **章どうしにも上下がある。**章の区切りの行も、段に応じて右へ寄る。番号を振るのは横に並べて数えられる章だけで、前置き・まとめ・補いの章には振らない |
| **R7** | **色が何を表すかを覚えさせない。**凡例まで目を戻させず、色の付いた所に言葉の札を添える。ただし、縦の線の上に文字を重ねない |
| **R8** | **拡大・縮小の操作は付けない。**切り替えたいのは画面の倍率ではなく、離れて見ると要点だけ、近づくと細部まで、という中身のほう |
| **R9** | **再生の速さの選択肢には、必ず「等倍」を置く。**「1×」のような書き方はしない |
| **R10** | **画面の横幅は、ウィンドウの幅に合わせて伸び縮みする。**詰まりすぎも空きすぎも無いように。ふだんの使い方で横にスクロールさせない |
| **R11** | **左右の欄は、中央をスクロールした位置に合わせて動く。そうするのは「通読」のときだけ。**追体験のときは、スクロールしても時計は進めない（進められると、まだ来ていない時刻の中身を出すことになり、R2b に反する） |

## 細かさ（迷ったら、まとめる側へ）

| 欄 | 細かさ | 何のためか |
|---|---|---|
| 左の欄（論点） | **5 つ前後** | 会議の最中に目をやる所。全部で幾つあり、いまがその何番目かが分かれば足りる |
| 中央の欄（カード） | **1〜2 分ごとに 1 枚** | あとで読み返す所。見出しと詳しい説明の 2 段 |
| 右の欄（逐語） | **すべて** | 発言の裏づけを見る所。**縮めない**（要約すると、何を話していたのかが分からなくなる） |

## どこで守らせているか

検査器は 2 つあり（`tools/rt.py` と、ページの `src/verify.js`）、どちらも規則表 `format/rules.json` に従います。規則に反する追記は、1 行も書かずに断ります。

- **R1**: 位置を後から動かす手段を、記録の形に持たせていません（訂正 `fix` で `t` は直せない）。そのうえで検査器が、置ける範囲を縛ります。時刻は 0 以上、カードは根拠に挙げた発話の時刻の間、括りの印は範囲の始まり以降、決着は保留を開いた時刻以降（P29・P15）。範囲の中のどこに置いたかが正しいかまでは、機械では見られません
- **R2**: 検査器が、聞き終えていない時刻・無い id・窓の飛ばし・決まった窓との食い違い・1 つの窓に入れすぎ（40 発話まで）を断ります（P04・P05・P07・P09・P10）。40 発話で切った窓は、次の窓に回した発話の時刻で終わり、その時刻と同じ時刻の発話は窓に入れません（同じ時刻の発話だけで 41 件以上続くときに限り、幅 0 の窓に 40 件）。切った先の時刻を、まだ渡していない窓に持たせないためです。窓を決めるのは道具で、分析役ではありません
- **R2c**: 検査器が見るのは、毎ステップちょうど 1 つの `note` があること（P17）と、カードの見出し・詳細に推量の言葉（だろう・かもしれない・おそらく）があるときの警告（P24。警告だけで、書くのは止めない）までです。**推量の言葉を使わずに言い切った見込みは、機械では見分けられません。**見込みをカードにしないことは、分析役への指示（`prompts/analyst.md`）で守らせています
- **R2b**: `tools/audit_r2b.py` が、書き終えた判断ログを後から調べ、先を読んだ跡を数えます。ページの追体験は、時刻 T までに書き終えたステップだけを畳んで描きます（右の逐語も、そのステップが渡した発話まで）。聞いている間も、右の逐語に出すのは窓として分析役に渡した発話までで、窓を待っている発話は件数だけを出します
- **右の逐語の「すべて」**（発話を黙って落とさない）: 中断している間に届いた発話（打った・貼った・OS の音声入力）も捨てず、届いた時刻のまま、再開した後の最初の窓に入れます。聞き終えるときは、まだ窓に入っていない発話を最後の窓として渡してから `end` を書きます。ページは「聞き終える」がこれを一度に行い、`tools/rt.py` は `next --last` → `append` → `end` の順に打ちます（`end` は、渡していない発話が残っていれば何も書かずに断ります）。どちらも、素材ログのどの発話もどれかの窓に入ってから記録が閉じ、最後の窓の終わりも同じ決め方（聞き終えた時計の秒。幅は窓幅の 3 倍まで）です（`format/FORMAT.md`）。ページの音声認識の入口では、止めた後に認識が返した言葉も捨てず、止めた認識（中断の前に止めたものも）の終わりの知らせを合わせて 3 秒まで待ってから最後の窓に入れます。それより後に届いた言葉は記録に入れませんが、黙っては捨てず、素材ログに出来事（`late`）として残し、入口の知らせの欄に出します
- **R5・R7・R9・R10・R11**: `tests/e2e/` の画面の試験が見ます。R8（倍率を変える CSS が無いこと）と R9（「等倍」があり「1×」が無いこと）は、`build_html.py` も組み立てるたびに見ます
- **R4・R6 と細かさ、R8 の中身の切り替え**: 画面の作りと、分析役への指示（`prompts/analyst.md`）で守ります
