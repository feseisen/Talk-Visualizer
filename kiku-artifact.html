聞き取りの設定

アーティファクトの中では、どれも触らなくても始められます。ZIP 版では「整理する AI」だけ選べば始められます。

同じ記録の名前を入力して始めると、その記録の続きに書きます。区切りの長さは、AI に一度に渡す長さです（貼った文字起こしは 120 秒）。

「この画面の Claude」は、この画面を開いている人の Claude を使います（API キーは要りません。使った量は、開いている人の使用量に数えられます）。最初に使うとき、この画面から Claude を使うことを許可するかの確認が 1 回出ます。

記録

保存すると、判断ログと素材ログ（文字起こしの全文）が、このアーティファクトを開ける人全員が読める場所に入ります。会議の中身を共有してよいときだけチェックを入れます。
API の設定（API キーはこの画面で貼る。ページには入っていない）

API を選ぶと、区切りが終わるたびに、指示文（約 1.3 万字）と次のものを API の提供元へ送ります：「前から知っていたこと」、その区切りの発言（話者名つき）、未確定の区切りの発言（話者名つき。その区切りが片付くまで毎回）、答えを待っている問いと尋ねた人の名前、最上位の候補の見出し、章の名前、宣言された数え上げの項目、最近のカード 8 枚までの見出しと話者名、最近の所感 3 つまで、いまの日時。呼び出しに失敗したときや、返事が決まった形式に合わないときは、その理由を添えて同じ区切りをもう一度送ります（1 つの区切りで 3 回まで）。送ってよい会議かは、社内のルールに従ってください。

API（Anthropic）は、いつも api.anthropic.com に送ります（「送り先の URL」の欄は空のままにしてください。モデルは空なら既定のものを使います）。API（OpenAI 互換）は、URL の後ろに /chat/completions を付けて送ります。API キーのヘッダー名が違う送り先（Azure など）や、URL に ?api-version= を付ける送り先は、いまは設定できません。

保存すると、API キーはこの PC の中に暗号化されずに残り、ファイルとして開いた他のページからも読める場所に置かれます。共有の PC では選ばないでください。

ドラッグ＆ドロップしてもインストールできないとき
  • まず、拡張機能の画面の右上の「デベロッパー モード」がオンか確かめます。オフのままドロップすると、ZIP がダウンロードされるだけでインストールされません。
  • それでもインストールできなければ、ZIP を展開し、拡張機能の画面の「パッケージ化されていない拡張機能を読み込む」で、展開したフォルダ（manifest.json のある所）を選びます。
  • 「デベロッパー モード」のスイッチが灰色で押せない PC（会社の PC などで、管理者が止めているとき）では、この拡張機能はインストールできません。その PC では「文字起こしを貼って組み上げる」を使います。画面に「管理されている」という表示が出ているだけなら、止められているとは限りません。
  • 前に古いバージョン（拡張機能の画面での名前は「kiku 橋」）をフォルダから読み込んでいたら、拡張機能の画面でそれを削除します。

この画面の中では音声を取り込めないので、会議の音を文字にするのは拡張機能の側です。拡張機能そのものは通信しません（音声を Google に送るのは、送ることを承知したときの Chrome の音声認識です）。拡張機能が無くても「文字起こしを貼って組み上げる」は使えます。

画面全体の音が拡張機能に届くか、文字になるかを測ります。人が話している YouTube の動画などを流したまま押します。最後の 12 秒は音声を Google のサーバーへ送るので、外に出てよい音だけを流します。

    使い方

    Enter か、入力が 2 秒止まったら確定して 1 発話になる。行の先頭に「名前: 本文」（半角の「:」のあとに空白）か「名前：本文」（全角の「：」）と書くと、名前が話者になる。名前は 20 字まで、空白を含まず、数字で始まらないものだけ。「15:00までに」「9:00 から」「https://…」のような行は、行の全体が本文になる（話者は無し）。表から貼った「時刻・話者・本文」をタブで区切った行は、時刻の列を使わず、届いた時刻で記録する。一時停止の間に打った行も捨てず、再開した後の最初の区切りに入る。OS の音声入力（Windows は Win+H）もこの欄に打てる。

    ブラウザ音声認識

    使い方

    このブラウザが持つ音声認識で、この PC のマイクの音を聞き取る（オンライン会議の相手の声をヘッドホンで聞いているときは入らない）。この PC の中だけで文字にできるかをブラウザに尋ね、できると答えたら、この PC の中で文字にする（音声は外へ出ない）。できないときは音声を提供元のサーバーへ送ることになるので、下のチェックを入れないと始めない。このチェックは保存されないので、ページを開き直したら入れ直す。この PC の中で文字にすると決めて始めた後に失敗しても、黙ってサーバーへ切り替えることはしない。何も聞き取れないまま続けて 5 回失敗したときや、マイクの許可が無いときは止めて、そう出す。「停止」を押すと、認識の終わりの知らせを 3 秒まで待ち、その間に届いた言葉も最後の区切りに入れてから閉じる。

    ダウンロードするときに音声は送らない。データのダウンロードが止められている PC ではダウンロードできないことがある。
